# MVP機能スコープ

2026-09-01 時点で確定した機能スコープ（差別化戦略は 2026-09-03 に追加）。

## ⭐️ プロダクトの幹

**「気分で見つかる、行きつけと繋がる」— カフェ好きのためのSNS**

差別化の詳細は [positioning.md](./positioning.md) 参照。

以下の2軸を強化する機能に投資リソースを集中する:
- **幹A: 気分・シーン起点の発見体験**
- **幹C: オーナーとの信頼つながり**

## 基本仕様

- ログイン不要で閲覧可能
- アカウント作成: **メールアドレス + パスワード**（電話番号/SMS OTP は MVP 対象外 → [pending-items B6](./pending-items.md)）
- ログイン後の可能操作: 投稿・コメント・お気に入り登録・いいね
- タグ検索: エリア / 雰囲気 / 利用機会（一人・朝・デート等）
- 投稿形式: 写真 + カフェのエリア + 店名 + コメント（短文）or ブログ

## MVPで追加する機能

| 機能                         | 概要                                                        |
| ---------------------------- | ----------------------------------------------------------- |
| 地図表示（マップビュー）     | 現在地・エリアからカフェを地図上で探索                      |
| フォロー / タイムライン      | 「フォロー中」と「発見（Explore）」タブを分ける             |
| 保存（行きたいリスト）       | お気に入りとは別に「行きたい」を保存                        |
| 営業時間・定休日・混雑度     | 訪問可否の判断材料                                          |
| 通報・ブロック・NGワード     | 若年層向けサービスの安全対策                                |
| 画像EXIF自動除去             | アップロード時に位置情報を自動削除                          |
| カフェ経営者用ダッシュボード | 公式認証バッジ、投稿分析、店舗情報編集                      |
| **年齢確認 / 未成年保護**    | 生年月日必須、13歳未満は登録不可、13-17歳は保護者同意フロー |
| **下書き自動保存**           | ブログ形式投稿の離脱防止（損失回避）                        |

## 差別化のための追加機能（2026-09-03）

### 幹A: 気分・シーン起点の発見体験

| 機能                 | 概要                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------- |
| 気分入り口           | S_HOME 最上部に「今、どんなカフェ気分？」セクション（[ひとり時間][朝][デート][雨の日]等）   |
| シーンタグの第一級化 | `tags.category='occasion'` を最優先表示、エリアタグは絞り込みに格下げ                       |
| オンボーディング拡張 | ホームエリア + 好きな気分（シーン）を必ず選択させる（`S_ONBOARD_INTERESTS` はスキップ不可） |
| シーン別レコメンド   | 「あなたと同じ気分の人が保存したカフェ」提示                                                |
| シーン開拓バッジ     | 朝カフェマスター / 雨の日マスター / 集中マスター 等                                         |

### 幹C: オーナーとの信頼つながり

| 機能                         | 概要                                                           |
| ---------------------------- | -------------------------------------------------------------- |
| オーナー限定投稿フォーマット | 「豆知識」「今日のおすすめ」「臨時休業告知」「新メニュー」の型 |
| 常連認定 (Regular Customer)  | オーナーがユーザーに「常連さん」バッジを付与                   |
| オーナー公式返信             | ユーザー投稿へオーナーが公式返信可能、一般コメントと区別表示   |
| 常連分析                     | 経営者ダッシュボードで常連数推移・投稿パターン分析             |
| 「私の行きつけ」セクション   | マイページに、常連認定されたカフェを強調表示                   |

## 明示的にやらないこと（Instagramとの差別化）

- フォロー中心のフィード設計 → 気分ベース発見を主に
- 映え重視の写真フィルタ・編集機能 → 素の写真を推奨
- リール・ストーリーズ的短時間コンテンツ → 蓄積型コンテンツ優先
- DM（直接メッセージ）機能 → コメントで完結
- ショップ / アフィリエイト誘導の押し出し

## 採用する行動経済学要素

| 要素                   | 実装イメージ                                                                                                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| デフォルト効果         | 投稿時タグを位置情報から自動サジェスト                                                                                                                                    |
| ゲーミフィケーション   | 訪問数バッジ、エリア制覇マップ                                                                                                                                            |
| 返報性                 | いいねをくれた人への通知でリアクション促進（**通知部分は保留** — `notifications` 未作成のため [pending-items D35](pending-items.md)。いいね自体は 2026-09-19 に実装済み） |
| 選択のパラドックス回避 | タグ数制限、デフォルトソート「おすすめ」                                                                                                                                  |
| ピークエンド則         | 投稿完了時のマイクロアニメーション                                                                                                                                        |
| 損失回避               | 下書き自動保存 + 離脱前アラート                                                                                                                                           |

## フェーズ2以降に後回し

| 項目                                  | 理由                               |
| ------------------------------------- | ---------------------------------- |
| 社会的証明表示（「今週◯人が保存」等） | データ蓄積後に導入したほうが効果的 |
| 希少性表示（「今月あと3席」等）       | 情報源の確保が難しい               |
| アンカリング（価格比較表示）          | 価格データの整備が先               |

## 法務・運用上の対応事項

**「検証ベータ」（招待制・非公開運用）と「本公開」（広く集客）を分けて考える（2026-10-08決定、
[pending-items.md D66](pending-items.md#d66-利用規約プライバシーポリシーは専門家レビュー未了のドラフト)参照）。**
検証ベータは現行ドラフトのまま・無料相談のみで進め、有料の弁護士スポット相談は本公開の直前に行う。

**検証ベータの概要（[pending-items.md D67](pending-items.md#d67-招待制検証ベータの技術的準備)）:**
AIコミュニティの非公開チャット（検索エンジンに非公開）にリンクを投稿する形で配布。配布先を1箇所に
限定することが実質的な招待制になるため、招待コード等の技術的ゲートは作らない。2026-10-15公開
（10/16のオフライン交流会でのアピールに合わせる）〜2026-11-30締切（JST）、締切はサインアップの
Server Action側で技術的に新規登録を拒否する形で実施する。終了後のデータは残す方向で検討中だが、
投稿内容を確認してから最終決定する。

| 項目                                       | 検証ベータまでに要るか                                                         | 本公開までに要るか                                                       |
| ------------------------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| 利用規約 / プライバシーポリシー            | ドラフトのまま可（実装済み、専門家レビュー未了）                               | 専門家レビュー必須                                                       |
| 検索エンジン非掲載（`app/robots.ts`）      | 要る（実装済み・締切連動）                                                     | 要らない（本公開はむしろ掲載したい）                                     |
| サインアップ締切の技術的実装（2026-11-30） | 要る（実装済み）                                                               | -                                                                        |
| 削除依頼受付窓口                           | 要る（実装済み・`/takedown`）                                                  | -                                                                        |
| モデレーションフローの文書化               | 要る（実装済み・[moderation-runbook.md](../operations/moderation-runbook.md)） | -                                                                        |
| 特定商取引法に基づく表記                   | 不要（金銭取引が無いため）                                                     | [C3](pending-items.md#c3-収益化フラグの実装)で収益化を実装する際に再検討 |
