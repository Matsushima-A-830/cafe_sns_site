# ポジショニングと差別化戦略

**このドキュメントはプロダクトの「幹」を定義する。すべての機能・UX判断はここに立ち返る。**

## 1行ビジョン

> **「気分で見つかる、行きつけと繋がる」— カフェ好きのためのSNS**

## ターゲット再確認

- **メイン:** 日本の10〜20代でカフェが好きな若者
- **サブ:** 個人経営を中心とするカフェオーナー

## Instagram との対比表

| 観点 | Instagram | このサービス |
|---|---|---|
| 導線の入り口 | 「フォローの近況」を見る | **「今の気分に合うカフェ」を探す** |
| 検索の主軸 | ハッシュタグ / 場所 | **気分・シーン（ひとり時間・朝カフェ・雨の日 等）** |
| 店との関係 | 一方向の公式アカウント | **経営者認証 + 双方向コミュニケーション** |
| 発信の性格 | 自己表現・映え | **趣味の共有・記録** |
| 経営者への価値 | 広告色が強い | **常連コミュニティ形成 + 分析** |
| 情報の信頼 | 個人投稿依存 | **オーナー限定フォーマット + 認証バッジ** |

**核となる差別化:** カフェを「見せる/映える」場ではなく、**「気分で見つけて、行きつけと繋がる」場**として設計する。

---

## 差別化の2つの幹

### 幹A: 気分・シーン起点の発見体験

**コンセプト:** ユーザーが「今こういうカフェに行きたい」という気分から最短で理想のカフェに出会える。

**Instagramでは提供できない理由:** 汎用SNSのアルゴリズムには「気分」を第一級市民として扱う動機がない。カフェ特化ドメインだからこそ成立するUX。

**主要施策:**

1. **トップ画面の気分入り口** — ホーム最上部が「今、どんなカフェ気分？」から始まる
2. **シーンタグを第一級市民に** — `tags.category = 'occasion'` が最優先表示。エリアタグは絞り込みに格下げ
3. **シーン別レコメンド** — 「あなたと同じ気分の人が保存したカフェ」等
4. **シーン開拓バッジ** — 「朝カフェマスター」「雨の日マスター」「集中カフェマスター」等でシーン多様性を促進
5. **オンボーディング** — ホームエリアと同じ比重で「好きな気分」を必ず選ばせる

**採用する気分カテゴリ:**

以下は方向性を示すグルーピング。**実際に投入する30個の確定セットは [seed/curated-tags-initial-set.md](../seed/curated-tags-initial-set.md) が正**（このドキュメントの表は戦略の意図を説明するためのもので、タグの定義ではない）。

| シーン | 該当する厳選タグ（MVP） |
|---|---|
| ひとり時間 | #ひとり時間 #勉強 |
| 朝 | #朝カフェ #モーニング #早朝営業 |
| デート | #デート #女子会 #夜カフェ |
| リラックス | #のんびり #静か |
| 雨・寒い日 | #雨の日 |
| ワーク | #ワーク #Wi-Fi #電源 |
| 子連れ | #子連れOK |

「#集中」「#読書」「#記念日」「#贅沢」等は MVP の厳選セットに含めない。ユーザー投稿タグ（`is_curated=false`）として蓄積し、利用が伸びたら昇格を検討する。

### 幹C: オーナーとの信頼つながり

**コンセプト:** 個人経営カフェのオーナーとユーザーが直接繋がり、行きつけを深めていくエコシステム。

**Instagramでは提供できない理由:** 一般SNSのフォロー構造は「店↔客」の関係を特別扱いできない。認証・信頼・常連文脈が薄れる。

**主要施策:**

1. **経営者認証バッジ** — （既に設計済み）
2. **オーナー限定投稿フォーマット** — 「豆知識」「今日のおすすめ」「臨時休業告知」「新メニュー」等の型
3. **常連認定 (Regular Customer)** — オーナーが「常連さん」バッジをユーザーに付与できる
4. **オーナーからの公式返信** — ユーザー投稿へオーナーが公式コメントできる（一般ユーザーコメントと区別表示）
5. **オーナーダッシュボードで常連分析** — 常連数の推移、常連の投稿パターン分析
6. **「行きつけ」概念の可視化** — マイページに「私の行きつけカフェ」セクション（オーナー認定された店を強調）

---

## 幹A と 幹C を組み合わせる価値

- **ユーザー側の物語:** 「気分で出会ったカフェ」→「気に入って通う」→「オーナーに認識される」→「常連認定」→「行きつけを持つ喜び」
- **オーナー側の物語:** 「認証取得」→「気分タグでの流入分析」→「常連認定で関係深化」→「継続来店に繋がる」
- 両者が同じサービスで幸せになる**双方向エコシステム**

## 明示的にやらないこと（Instagramとの差別化のため）

- **フォロー中心のフィード設計** — 発見（気分ベース）を主にする
- **「映え」重視のフィルタ・編集機能** — 素の写真を推奨、リッチな加工はInstagramに任せる
- **リール・ストーリーズ的な短時間コンテンツ** — 蓄積型（記録・ブログ）を主軸に
- **DMコミュニケーション** — 直接メッセージは提供しない（コメントで完結）
- **ショップ機能・アフィリエイト誘導の押し出し** — MVPでは商業色を薄く

## 幹B（フェーズ2以降）

**「カフェ好きコミュニティ・オフライン連動」** はMVPには含めないが、将来的な拡張候補:

- 趣味グループ（「朝活カフェ部」等）
- オフラインイベント機能（カフェ巡り会）
- 「似た好みの人」マッチング
- チェックイン機能（「今このカフェにいます」）

MVP でのユーザー数が一定規模を超えたら幹B を検討。

## 判断基準

新機能追加時、以下を自問する:

1. **幹A（気分検索）を強化するか？**
2. **幹C（オーナー連携）を強化するか？**
3. **どちらでもなければ、なぜ必要か？** — 明確な理由がなければ後回し

「Instagramでもできる機能」を追加する前に、上記3問を通す。
