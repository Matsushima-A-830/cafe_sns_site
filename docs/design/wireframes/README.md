# ワイヤーフレーム

MVP主要画面のレイアウトをテキスト/ASCIIで示します。デザインの最終稿ではなく、**要素配置と情報階層の合意形成**を目的としたスケッチです。

## 対応端末とブレークポイント

| 端末 | 想定幅 | Tailwindプレフィックス | 主レイアウト |
|---|---|---|---|
| モバイル | ~ 767px | 無印 | 単一カラム + ボトムナビ |
| タブレット | 768 - 1023px | `md:` | 2カラム or 拡張モバイル |
| PC | 1024px ~ | `lg:` `xl:` | サイドナビ + メイン + 補助カラム |

**方針:** モバイルファースト。タブレットは基本的にPCの縮小版として設計し、必要に応じてモバイル寄りへ切り替え。以降の各画面は「モバイル」「PC」の2種を主に示し、タブレットの扱いは注記で補足します。

## ASCII凡例

```
+---+       枠線
[ラベル]    ボタン
< 入力 >    テキスト入力欄
[ ▼ ]       セレクトボックス
( )         ラジオボタン
[ ]         チェックボックス
▲▼◀▶      矢印/戻る/展開
━━━         強調ボーダー / タブ選択中
---         区切り線
###         セクションタイトル
{変数}      動的値
Card:...    カードコンポーネントの略記
```

## 共通コンポーネント

### モバイル: グローバルヘッダー

```
+----------------------------------------+
| [ロゴ]              [検索] [通知] [+]  |
+----------------------------------------+
```

- 左: サイトロゴ（タップでホーム）
- 右アイコン: 検索・通知・投稿作成
- 未ログイン時: 通知アイコンは非表示、右端に [ログイン] ボタン
- スクロールで自動的に縮小 or 隠す（ピークエンド則: 主要動作を邪魔しない）

### モバイル: ボトムナビ（ログイン後のみ）

```
+----+----+----+----+----+
|ホーム|発見|投稿 |地図 |マイ|
+----+----+----+----+----+
```

- 中央の「投稿」を大きめに（Fitts法則）
- アクティブタブは強調ボーダー

未ログイン時のボトムナビ:

```
+------+------+------+------+
| ホーム| 発見 | 地図 |ログイン|
+------+------+------+------+
```

### PC: グローバルヘッダー

```
+-----------------------------------------------------------------------+
| [ロゴ] ホーム  発見  地図    < 検索                >  [+ 投稿][通知][アイコン]|
+-----------------------------------------------------------------------+
```

- 中央: 常時表示の検索ボックス（トップナビ内）
- 右: 投稿ボタン（primary）・通知・プロフィールアイコン
- 未ログイン時: [ログイン] [新規登録] ボタン

### PC: サイドナビ（ログイン後）

```
+---------------------+
| [ロゴ]              |
+---------------------+
| ●ホーム             |
|  発見               |
|  地図               |
```

## 全画面共通の行動経済学的配慮

- **デフォルト効果** — フォームは「多くのユーザーが選ぶ選択肢」を初期選択する
- **選択のパラドックス回避** — タグ選択・カテゴリ選択は最大数を制限し、厳選タグを優先
- **返報性** — アクション（いいね等）を受けたら通知でリターンを促す
- **ピークエンド則** — 完了画面と成功アクションに小さな喜びを配置
- **損失回避** — 破棄操作は必ず確認、下書きは自動保存＋離脱前アラート

## タブレット時の共通挙動（採用方針: PC寄せ + 一部モバイル要素）

Tailwindブレークポイントで以下のように分岐:

| BP | 幅 | レイアウト適用 |
|---|---|---|
| 無印 | ~ 767px | モバイル（単一カラム + ボトムナビ） |
| `md:` | 768px ~ | **タブレット寄り**（PC寄せ、ただし補助カラム非表示・サイドナビはアイコンレール） |
| `lg:` | 1024px ~ | **PC基本**（サイドナビ label 表示・補助カラム表示） |
| `xl:` | 1280px ~ | **PC贅沢**（3列グリッド等） |

### タブレット時（`md:` 適用）の具体差分

- サイドナビ: 表示、ただし幅 64px の**アイコンレール**（labelは非表示）
- 右補助カラム: **非表示**（メインフィード優先）
- ボトムナビ: **非表示**（サイドナビで代替）
- 投稿ボタン: ヘッダー右に **primary** 配置（アイコンレール底部ではなく）
- カード列数: 2列（`lg:` で3列、`xl:` で4列）
- モーダル・シート: PC同様の中央配置
