## S_SIGNUP（新規登録: 認証情報入力）

**登録手段は MVP ではメールアドレスのみ。** 電話番号（SMS OTP）は外部SMSプロバイダの契約が必要で Supabase の無料枠に含まれないため、MVP では提供しない（[pending-items B6](../../product/pending-items.md)）。

**ステップ表示の設計方針:**
- 基本フローは全員 **3ステップ** (認証情報 → OTP → 生年月日)
- 未成年（13〜17歳）と判定された場合のみ、生年月日入力後に **保護者同意ステップ** が追加される
- ステップ表示は基本「(1/3)」「(2/3)」「(3/3)」、保護者同意ステップのみ「追加ステップ: 保護者同意」と別ラベルで表示（分数を混乱させないため）

### モバイル

```
+----------------------------------------+
| [<戻る]                                |
+----------------------------------------+
|              [ロゴ]                    |
|         新規登録 (1/3)                 | <- 進捗表示
| ●○○                                    |
+----------------------------------------+
| メールアドレス                          |
| < ______________________ >             |
|                                        |
| パスワード（8文字以上、英数字混合）    |
| < ______________________ >    [表示]   |
|                                        |
| パスワード（確認）                      |
| < ______________________ >             |
+----------------------------------------+
| [ ] 利用規約 と プライバシー に同意    |
+----------------------------------------+
| [次へ]                    (primary)    |
+----------------------------------------+
|                                        |
| すでにアカウントをお持ちの方            |
| [ログインへ]                            |
+----------------------------------------+
```

## S_ONBOARD_INTERESTS（好きな気分の選択）

**⭐️ 幹A:** ホームエリアと同じ比重で「好きな気分（シーン）」を選ばせる。**このステップだけはスキップ不可**（[positioning.md 幹A 施策5](../../product/positioning.md)）。

### モバイル

```
+----------------------------------------+
| 準備 (3/3)                             |
| ●●●                                    |
+----------------------------------------+
| どんなカフェ気分が好きですか？          |
| (1〜5つ選んでください)                  |
+----------------------------------------+
| 選択済み: 2 / 5                         |
+----------------------------------------+
| ┃ 気分・シーン ┃ 雰囲気                 | <- シーンが既定タブ
| ──────────                              |
+----------------------------------------+
| [✓ 朝カフェ] [✓ ひとり時間] [デート]   |
| [勉強]    [ワーク]    [雨の日]         |
| [のんびり] [夜カフェ] [女子会]         |
|                    [もっと見る ▶]      |
+----------------------------------------+
| [はじめる！]              (primary)    |
+----------------------------------------+
```

- **既定タブは「気分・シーン」**（`tags.category='occasion'`、`priority=100`）。「雰囲気」（`mood`）は2番目のタブ
- **1つ以上の選択を必須にする** — 未選択の間は [はじめる！] を disabled にし、スキップ導線は置かない。気分起点の発見体験（幹A）の初期データがここでしか取れないため
- 選択済みバッジで進捗を可視化
- **選択のパラドックス回避:** 初期表示9個 + 「もっと見る」
- 完了時に `profiles.onboarded_at` へ `now()` を書き込む。これがオンボーディング完了の唯一の判定材料で、middleware はこれを見て未完了ユーザーを `/onboarding` へ戻す（[routing.md](../../architecture/routing.md#middlewarets-設計)）
- **選択したタグの保存先は未決**（[pending-items A7](../../product/pending-items.md)）。`user_interest_tags` を新設する案が有力
- 完了時、`S_MY_HOME` に遷移。**ピークエンド則:** 「ようこそ！」トースト + 小さなアニメーション

### PC（オンボーディング共通）

- サイドナビ・フッター非表示、中央カード幅 640px
- 進捗は上部に横型プログレスバー
- 各ステップの入力欄は同レイアウトを維持（認知負荷低減）
