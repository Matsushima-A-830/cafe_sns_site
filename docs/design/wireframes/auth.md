# 認証・オンボーディング画面

サインアップは年齢確認を挟むため、複数画面に分割。共通コンポーネントは [README.md](./README.md) を参照。

## S_LOGIN（ログイン）

### モバイル

```
+----------------------------------------+
| [<戻る]                                |
+----------------------------------------+
|                                        |
|              [ロゴ]                    |
|                                        |
|         ログイン                        |
|                                        |
| メール or 電話番号                      |
| < ______________________ >             |
|                                        |
| パスワード                              |
| < ______________________ >    [表示]   |
|                                        |
| [ログイン]              (primary, full) |
|                                        |
| [パスワードを忘れた方はこちら]         |
|                                        |
| --------  または  --------              |
|                                        |
| アカウントをお持ちでない方              |
| [新規登録へ]                            |
|                                        |
+----------------------------------------+
```

### PC

- 中央寄せカード（幅 480px）に同じ内容
- 背景に淡いカフェイメージ画像を配置
- サイドナビ・フッターは非表示（集中導線）

## S_SIGNUP（新規登録: 認証情報入力）

**ステップ表示の設計方針:**
- 基本フローは全員 **3ステップ** (認証情報 → OTP → 生年月日)
- 未成年（13〜17歳）と判定された場合のみ、生年月日入力後に **保護者同意ステップ** が追加される
- ステップ表示は基本「(1/3)」「(2/3)」「(3/3)」、保護者同意ステップのみ「追加ステップ: 保護者同意」と別ラベルで表示（分数を混乱させないため）

### モバイル

```
+----------------------------------------+
| [<戻る]                                |
+----------------------------------------+
|              [ロゴ]                    |
|         新規登録 (1/3)                 | <- 進捗表示
| ●○○                                    |
+----------------------------------------+
| 登録方法                                |
| ( ● ) メールアドレス                    |
| ( ○ ) 電話番号                          |
+----------------------------------------+
| メールアドレス                          |
| < ______________________ >             |
|                                        |
| パスワード（8文字以上、英数字混合）    |
| < ______________________ >    [表示]   |
|                                        |
| パスワード（確認）                      |
| < ______________________ >             |
+----------------------------------------+
| [ ] 利用規約 と プライバシー に同意    |
+----------------------------------------+
| [次へ]                    (primary)    |
+----------------------------------------+
|                                        |
| すでにアカウントをお持ちの方            |
| [ログインへ]                            |
+----------------------------------------+
```

**次の画面: OTP or メール認証**

```
+----------------------------------------+
| [<戻る]  新規登録 (2/3)                |
| ●●○                                    |
+----------------------------------------+
| 確認コードを送信しました                |
| {メール/電話} 宛のコードを入力してください|
+----------------------------------------+
| < _  _  _  _  _  _ >                   |
|                                        |
| [認証]                                 |
|                                        |
| コードが届かない → [再送する]         |
+----------------------------------------+
```

**次の画面: 生年月日入力（年齢確認）**

```
+----------------------------------------+
| [<戻る]  新規登録 (3/3)                |
| ●●●                                    |
+----------------------------------------+
| 生年月日を入力してください              |
|                                        |
| 【重要】                                |
| ・13歳未満はご登録いただけません        |
| ・13〜17歳は保護者の同意が必要です      |
| ・年齢確認のためのみに利用します        |
+----------------------------------------+
| 年 [ ____ ▼]   月 [ __ ▼]   日 [ __ ▼]|
+----------------------------------------+
| [次へ]                    (primary)    |
+----------------------------------------+
```

- 「重要事項」を上に明示（未成年ブロックに驚かせないため）
- 生年月日は年→月→日の順（日本の慣行に合わせる）

## S_MINOR_CONSENT（13〜17歳: 保護者同意）

「(4/4)」のような通番ではなく **「追加ステップ: 保護者同意」** として表示し、成人ユーザーの3/3完了体験と混同しないようにする。

### モバイル

```
+----------------------------------------+
| [<戻る]  追加ステップ: 保護者同意       |
| ●●●● + [追加]                          |
+----------------------------------------+
| 保護者の同意が必要です                  |
|                                        |
| 13〜17歳の方は、保護者の方の同意を      |
| いただく必要があります。                 |
|                                        |
| 保護者の方に確認メールをお送りします。  |
| メール内のリンクをクリックしていただく   |
| ことで、アカウントが有効になります。    |
+----------------------------------------+
| 保護者のメールアドレス                  |
| < ______________________ >             |
|                                        |
| [ ] 私は上記メールアドレスの所有者      |
|     から同意を得ることを約束します      |
+----------------------------------------+
| [同意メールを送信]        (primary)    |
+----------------------------------------+
```

+----------------------------------------+
| はじめまして！                          |

+----------------------------------------+
| プロフィール画像                        |
|         [○ アップロード ]              |
|         (省略可能)                      |
+----------------------------------------+

| < @______________ >     [重複チェック] |
| ※ あとから変更できません               |

| < ______________________ >             |
+----------------------------------------+
| ひとこと自己紹介 (省略可能)             |

## S_ONBOARD_AREA（ホームエリア選択）

### モバイル

```
+----------------------------------------+
| 準備 (2/3)                             |
| ●●○                                    |
+----------------------------------------+
| よく行くエリアはどこですか？            |
| おすすめの投稿に活用します              |
+----------------------------------------+
| 現在地から検索                          |
| [ 位置情報を使う ]                      |
+----------------------------------------+
| よく選ばれるエリア                      |
| [渋谷]  [表参道]  [恵比寿]              |
| [新宿]  [下北沢]  [吉祥寺]              |
| [その他のエリアを検索 ▶]                |
+----------------------------------------+
| 選択済み: 渋谷                          |
+----------------------------------------+
| [次へ]                    (primary)    |
| [スキップ]                              |
+----------------------------------------+
```

- **デフォルト効果:** 東京主要エリアを初期表示（ターゲット層に合わせて）
- 位置情報許可を促す（後の投稿時タグサジェストにも使う）

## S_ONBOARD_INTERESTS（興味タグ選択）

### モバイル

```
+----------------------------------------+
| 準備 (3/3)                             |
| ●●●                                    |
+----------------------------------------+
| 好きな雰囲気を教えてください            |
| (最大5つまで)                           |
+----------------------------------------+
| 選択済み: 2 / 5                         |
+----------------------------------------+
| ┃ 雰囲気 ┃ 利用シーン                  |
| ─────                                  |
+----------------------------------------+
| [✓ 静か]  [✓ 朝カフェ]  [おしゃれ]     |
| [レトロ]  [Wi-Fi]  [デート]             |
| [勉強]    [一人時間] [ワークスペース]  |
+----------------------------------------+
| [はじめる！]              (primary)    |
| [スキップ]                              |
+----------------------------------------+
```

- 選択済みバッジで進捗を可視化
- **選択のパラドックス回避:** 初期表示9個 + 「もっと見る」
- 完了時、`S_MY_HOME` に遷移。**ピークエンド則:** 「ようこそ！」トースト + 小さなアニメーション

### PC（オンボーディング共通）

- サイドナビ・フッター非表示、中央カード幅 640px
- 進捗は上部に横型プログレスバー
- 各ステップの入力欄は同レイアウトを維持（認知負荷低減）
