# 投稿作成

短文とブログの2形式を用意し、下書き自動保存で離脱コストを下げる（損失回避）。

## エントリ選択（+ボタン押下時のシート）

### モバイル

```
+----------------------------------------+
|                                        |
|          何を投稿しますか？             |
|                                        |
|  ┌─────────────────────────────────┐  |
|  │ [写真] 写真＋短文                │  |
|  │        1〜N枚 + 短いコメント     │  |
|  └─────────────────────────────────┘  |
|  ┌─────────────────────────────────┐  |
|  │ [文]   ブログ                    │  |
|  │        タイトル+本文で詳しく     │  |
|  └─────────────────────────────────┘  |
|                                        |
|         [キャンセル]                    |
|                                        |
|  下書き 3件あります [続きを書く ▶]    | <- あれば表示
+----------------------------------------+
```

- ボトムシート形式（PCでは中央モーダル）
- 下書きが存在するとエントリで案内（損失回避）

## S_POST_SHORT（短文投稿）

### モバイル

```
+----------------------------------------+
| [<キャンセル]  短文投稿      [投稿する]|
+----------------------------------------+
| ┌──────┐┌──────┐┌──────┐┌──────┐    |
| │写真1 ││写真2 ││写真3 ││ ＋   │    | <- 1〜10枚まで
| │      ││      ││      ││追加  │    |
| └──────┘└──────┘└──────┘└──────┘    |
| ※ 位置情報は自動で削除されます        |
+----------------------------------------+
| どのカフェですか？                      |
| [ カフェを検索・選択           ▶]     |
| 選択中: {カフェ名}  ✕                  |
+----------------------------------------+
| おすすめタグ (位置情報より)             |
| [+ 表参道] [+ 朝カフェ]               | <- ワンタップ追加
+----------------------------------------+
| タグ (最大5個)                          |
| [#朝カフェ ✕] [#Wi-Fi ✕]              |
| [+ タグを追加]                          |
+----------------------------------------+
| コメント                                |
| < ここに書いてください                >|
| <                                    >|
+----------------------------------------+
| 自動保存済み ・ 20秒前                 | <- 損失回避の可視化
+----------------------------------------+
```

**行動経済学の要素:**
- **デフォルト効果:** 位置情報からタグ自動サジェスト
- **選択のパラドックス回避:** タグ5個まで
- **損失回避:** 自動保存済み表示 + 離脱前ダイアログ

### PC

```
+----------------------------------------------------------------------------------+
| [キャンセル]                                                        [投稿する]  |
+----------------------------------------------------------------------------------+
|              +----------------------------------------+                            |
|              | [写真エリア]                            |                            |
|              +----------------------------------------+                            |
|              | カフェ選択 / タグ / コメント          |                            |
|              +----------------------------------------+                            |
|              | 自動保存済み ・ 20秒前                 |                            |
|              +----------------------------------------+                            |
+----------------------------------------------------------------------------------+
```

- 中央カード幅 720px、両サイドはグレーアウト（集中導線）

## S_POST_BLOG（ブログ投稿）

**採用エディタ: Tiptap（リッチテキスト）**
- 保存形式: JSON（ProseMirror）— XSS対策と表示柔軟性の両立
- 対応機能: 見出し（h2/h3）・太字・斜体・リンク・画像・引用・箇条書き・番号付きリスト
- 意図的に非対応: **下線**（リンクと視覚的に紛らわしい）・テーブル・カラム分割・カスタム色・フォント指定（選択のパラドックス回避）
- モバイル対応: フローティングツールバーが選択範囲上に出現


### モバイル

```
+----------------------------------------+
| [<キャンセル]  ブログ投稿    [公開する]|
+----------------------------------------+
| [ 下書き保存 ]              [ プレビュー ]|
+----------------------------------------+
| タイトル                                |
| < ______________________ >             |
+----------------------------------------+
| アイキャッチ画像                        |
| [ ＋ 画像を追加 ]                      |
+----------------------------------------+
| どのカフェですか？                      |
| [ カフェを検索・選択           ▶]     |
+----------------------------------------+
| タグ (最大5個)                          |
| [+ タグを追加]                          |
+----------------------------------------+
| 本文                                    |
| ┌──────────────────────────────────┐  |
| │ [B][I][H][リンク][画像][リスト]   │  | <- 簡易ツールバー
| ├──────────────────────────────────┤  |
| │                                    │  |
| │  本文を書いてください...          │  |
| │                                    │  |
| │                                    │  |
| │                                    │  |
| └──────────────────────────────────┘  |
+----------------------------------------+
| 公開範囲                                |
| ( ● ) 公開  ( ○ ) フォロワーのみ       |
+----------------------------------------+
| 自動保存済み ・ 15秒前                 |
+----------------------------------------+
```

- 保存形式は Tiptap JSON 単一。Markdown 記法は**入力ショートカット**としてのみ受け付ける（`## ` で見出しになる等）。Markdown テキストとしては保存しない
- 自動保存は15秒デバウンスで `drafts` を**上書き**する。バージョン履歴は持たない（[tables.md drafts](../../architecture/data-model/tables.md#drafts) は `UNIQUE (author_id, client_draft_key)` の1行）

### PC

```
+----------------------------------------------------------------------------------+
| [キャンセル]      [ 下書き保存 ] [ プレビュー ]              [公開する]         |
+----------------------------------------------------------------------------------+
| +---- 設定サイドバー ----+  +------------ 本文エディタ ---------------+          |
| | タイトル               |  | [Toolbar]                                 |          |
| | < ___________ >        |  |                                           |          |
| |                        |  |                                           |          |
| | アイキャッチ           |  |  ここに本文を書きます...                 |          |
| | [+ 画像]               |  |                                           |          |
| |                        |  |                                           |          |
| | カフェ                 |  |                                           |          |
| | [ 選択 ▶ ]             |  |                                           |          |
| |                        |  |                                           |          |
| | タグ                   |  |                                           |          |
| | [+ タグ]               |  |                                           |          |
| |                        |  |                                           |          |
| | 公開範囲               |  |                                           |          |
| | (●) 公開 (○) フォロワー|  |                                           |          |
| |                        |  |                                           |          |
| | 自動保存 15秒前        |  |                                           |          |
| +------------------------+  +-------------------------------------------+          |
+----------------------------------------------------------------------------------+
```

- 左: メタ情報サイドバー / 右: 本文エディタ
- PC向けに縦長エディタで長文執筆に集中しやすく

## 離脱前ダイアログ（S_POST_* 共通）

```
+----------------------------------------+
|                                        |
|     このまま離れますか？                |
|                                        |
|  未公開の変更は下書きとして             |
|  自動保存されています。                 |
|                                        |
|  下書き一覧からいつでも                 |
|  続きを書くことができます。             |
|                                        |
|  [続けて書く]     [下書きに保存して離脱]|
|                                        |
+----------------------------------------+
```

- 「破棄する」は目立たない位置 or 別画面（破壊的操作の摩擦）
- **損失回避** をUXに直接組み込む

## S_POST_SUCCESS（投稿完了）

### モバイル

```
+----------------------------------------+
|                                        |
|              ✓                         |
|          投稿しました！                 |
|                                        |
|  [完了時アニメーション]                 |
|                                        |
|  この投稿はエリア「渋谷」の             |
|  制覇マップに反映されます               |
|                                        |
|  [投稿を見る]                          |
|  [続けて投稿する]                       |
|                                        |
+----------------------------------------+
```

**ピークエンド則:**
- 完了時に軽いアニメーション（コンフェッティ、アイコンの跳ね）
- 「あなたの投稿がXX人に届きます」等、達成感を演出
- バッジ獲得タイミングと重なるならバッジ授与モーダルを続けて表示

## S_POST_OFFICIAL（オーナー限定投稿）

**⭐️ 幹C:** 認証済みオーナーのみアクセス可能。一般投稿とは別導線で、フォーマット化された公式コンテンツを投稿する。

### フォーマット選択（エントリ）

```
+----------------------------------------+
| [<戻る]  {カフェ名} 公式投稿           |
+----------------------------------------+
| どんな公式投稿ですか？                  |
+----------------------------------------+
| ┌─────────────────────────────────┐  |
| │ [☕] 今日のおすすめ              │  |
| │      日替わりメニュー・限定品    │  |
| └─────────────────────────────────┘  |
| ┌─────────────────────────────────┐  |
| │ [📖] 豆知識                      │  |
| │      店主から常連さんへの一言    │  |
| └─────────────────────────────────┘  |
| ┌─────────────────────────────────┐  |
| │ [🕐] 臨時休業・営業時間変更      │  |
| │      予定変更のお知らせ          │  |
| └─────────────────────────────────┘  |
| ┌─────────────────────────────────┐  |
| │ [🆕] 新メニュー                  │  |
| │      新しいメニューの告知        │  |
| └─────────────────────────────────┘  |
+----------------------------------------+
| [キャンセル]                            |
+----------------------------------------+
```

各フォーマットは `posts.official_format` に対応:
- `today_special` — 今日のおすすめ
- `tip` — 豆知識
- `closure` — 臨時休業・営業時間変更
- `new_menu` — 新メニュー

**フォーマット固有の入力項目（有効期限・価格・提供開始日・休業期間）は `posts.metadata` に保存する。** 専用カラムは増やさない。スキーマは [tables.md posts の `metadata`](../../architecture/data-model/tables.md#posts) に定義。

### フォーマット別入力画面

#### 今日のおすすめ (`today_special`)

```
+----------------------------------------+
| プレビュー: [✓公式] [今日のおすすめ]   |
| ┌────────────────────────┐            |
| │ [写真]                  │            |
| │ 季節限定マロンタルト   │            |
| │ ¥580                    │            |
| │ 今週入荷した...        │            |
| └────────────────────────┘            |
+----------------------------------------+
```

#### 豆知識 (`tip`)

```
+----------------------------------------+
| [<戻る]  豆知識             [投稿]     |
+----------------------------------------+
| 写真 (任意)                             |
| [ ＋ 写真を追加 ]                      |
+----------------------------------------+
| タイトル                                |
| < 例: 当店の豆へのこだわり >           |
+----------------------------------------+
| 本文（Tiptapエディタ）                 |
| ┌──────────────────────────────────┐  |
| │ [B][I][H][リンク]                 │  |
| ├──────────────────────────────────┤  |
| │                                    │  |

+----------------------------------------+
```

- ブログ形式に近い長文可
- 通常のブログ投稿と違い「オーナー」ラベルが常に付く

#### 臨時休業・営業時間変更 (`closure`)

```
+----------------------------------------+
| [<戻る]  臨時休業           [投稿]     |
+----------------------------------------+
| 種類                                    |
| ● 臨時休業  ○ 営業時間変更            |
+----------------------------------------+
| 期間                                    |
| 開始: [2026-09-15 ▼]                   |
| 終了: [2026-09-15 ▼]                   |
+----------------------------------------+
| 理由（任意）                            |
| < 例: 私用のためお休みさせていただきます>|
+----------------------------------------+
| ⚠ 「行きたい」に入れているユーザーに   |
|   通知が届きます                        |
+----------------------------------------+
```

**運用:** MVP では告知（公式投稿）のみで、`cafe_business_hours` の表示は書き換えない。営業時間そのものへの反映は `cafe_special_hours` テーブル導入後（[pending-items B5](../../product/pending-items.md)）

#### 新メニュー (`new_menu`)

```
+----------------------------------------+
| [<戻る]  新メニュー         [投稿]     |
+----------------------------------------+
| 写真（1〜3枚）                          |
| [ ＋ 写真を追加 ]                      |
+----------------------------------------+
| メニュー名                              |
| < 例: 秋の限定ブレンド >                |
+----------------------------------------+
| 価格                                    |
| < ¥ >                                  |
+----------------------------------------+
| 提供開始日                              |
| [2026-09-15 ▼]                        |
+----------------------------------------+
| 説明                                    |
| < 秋の味覚を...                      >|
+----------------------------------------+
```

### 実装メモ

- 認証済みオーナー以外は `S_POST_OFFICIAL` 導線をUIに出さない
- DB側でも `is_official=true` の INSERT を RLS でオーナーのみに制限
- カフェ詳細画面 (`S_CAFE_DETAIL`) の「オーナーから」セクションに表示される
- 一般投稿とは区別して、`notifications.type = 'official_post'` で通知する（[tables.md notifications](../../architecture/data-model/tables.md#notifications)）
- 「行きたい」「お気に入り」に入れているユーザーには公式投稿の通知を優先的に送る

## S_REPORT_FORM（通報フォーム）

### モバイル

```
+----------------------------------------+
| [<戻る]  通報する                      |
+----------------------------------------+
| 対象: {投稿タイトル or ユーザー名}     |
+----------------------------------------+
| 理由を選択してください                  |
|                                        |
| ( ) スパム / 宣伝                       |
| ( ) 嫌がらせ / 誹謗中傷                 |
| ( ) 未成年に不適切                      |
| ( ) 著作権侵害                          |
| ( ) 個人情報を含む                      |
| ( ) その他                              |
+----------------------------------------+
| 補足説明 (省略可能)                     |
| < ______________________ >             |
| < ______________________ >             |
+----------------------------------------+
| ※ 通報は運営で確認します。             |
|   結果は通知でお知らせします。          |
+----------------------------------------+
| [通報する]                (primary)    |
+----------------------------------------+
```

**理由の選択肢は `reports.reason` と1対1で対応**（spam / harassment / minor_risk / copyright / privacy / other。[tables.md reports](../../architecture/data-model/tables.md#reports)）。

**完了画面:**

```
+----------------------------------------+
|                                        |
|             ✓                          |
|       通報を受け付けました              |
|                                        |
|  運営で確認のうえ対応します。           |
|  結果は通知でお知らせします。           |
|                                        |
|  該当ユーザーをブロックしますか？       |
|  [ブロックする]  [しない]              |
|                                        |
+----------------------------------------+
```

- 完了直後にブロック提案（心理的にはこのタイミングが最も高転換）
