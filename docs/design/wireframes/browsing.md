# 閲覧系画面

未ログインでも到達可能な画面群。共通コンポーネント（ヘッダー、ボトムナビ等）は [README.md](./README.md) を参照。

## S_HOME / S_MY_HOME（ホーム / タイムライン）

未ログイン時とログイン後で同じ骨格を使い、コンテンツ（発見 or フォロー中）とCTAを切り替える。

**⭐️ 差別化の要:** 最上部に「今、どんなカフェ気分？」の入り口を配置し、シーンから探せることを最初に見せる（[product/positioning.md](../../product/positioning.md) 幹A）。

### モバイル

```
+----------------------------------------+
| [ロゴ]              [検索][通知][+]    |  <- ヘッダー
+----------------------------------------+
| ┃今、どんなカフェ気分？┃                | <- 気分入り口 (幹A)
| ┌──────┐┌──────┐┌──────┐┌──────┐    |
| │ひとり ││ 朝  ││デート ││雨の日│    | <- シーンチップ横スクロール
| │時間  ││カフェ││     ││     │    |
| └──────┘└──────┘└──────┘└──────┘    |
|                    [もっと見る ▶]      |
+----------------------------------------+
| ┃発見┃  フォロー中                      |  <- ログイン後のみタブ表示
| ─────                                  |
+----------------------------------------+
| [絞り込み: エリア ▼ / 気分 ▼]         |
+----------------------------------------+
| ┌────────────────────────────────┐   |
| │  [投稿画像 正方形]              │   |
| │                                │   |
| ├────────────────────────────────┤   |
| │ {ユーザー名} · 2h #渋谷区 #朝カフェ│   |
| │ 本文 抜粋 ここに...            │   |
| │ [いいね 12] [コメ 3] [保存]    │   |
| └────────────────────────────────┘   |
| ┌────────────────────────────────┐   |
| │  [投稿画像]                    │   |
| │  ...                           │   |
+----------------------------------------+
| [ホーム][発見][+投稿][地図][マイ]      |  <- ボトムナビ
+----------------------------------------+
```

**未ログイン時のヒント表示（フィード上端）:**

```
+----------------------------------------+
| ｜ ログインすると保存・いいねができます|
| ｜                     [ログイン ▶]   |
+----------------------------------------+
```

- 消えないバナー、ただし押し付けがましくない色調
- アクションを試そうとしたときにも同モーダルが登場（デフォルト効果 + タイミング）

### PC

```
+----------------------------------------------------------------------------------+
| [ロゴ] ホーム 発見 地図 < 検索                     > [+ 投稿][通知][アバター]  |
+---------+-------------------------------------------------------+----------------+
| ●ホーム | ┃発見┃ フォロー中                                    | おすすめタグ  |
|  発見   | ─────                                                | [#表参道]...  |
|  地図   +-------------------------------------------------------+                |
|  通知   | [投稿カード]                                          | おすすめユーザ|
|  マイ   | ...                                                   | ・{u} [フォロー]|
|  お気に | [投稿カード]                                          | ・{u} [フォロー]|
|  行きたい| ...                                                   |                |
|  下書き |                                                       | ヘルプ・規約   |
|  設定   |                                                       |                |
|         |                                                       |                |
| [+ 投稿]|                                                       |                |
+---------+-------------------------------------------------------+----------------+
| フッター（規約・特商法・お問い合わせ）                                            |
+----------------------------------------------------------------------------------+
```

- 3カラム（サイドナビ / メインフィード / 補助）
- カードグリッドは2列（幅 >= 1280px で3列に）

**タブレット:** サイドナビはアイコンレール、補助カラムは非表示。メインフィード1列。

## S_EXPLORE（発見）

`S_HOME` の「発見」タブと実質同じだが、ディープリンク時の直接表示画面として定義。
- モバイル: `S_HOME` の発見タブ選択状態
- PC: メインフィード＝発見、上部にサブタブ（「おすすめ」「新着」「近くのカフェ」）

```
+----------------------------------------+
| ┃おすすめ┃ 新着  近くのカフェ           |
| ─────                                  |
+----------------------------------------+
| [投稿カード 2列 or 3列グリッド]        |
| ...                                    |
+----------------------------------------+
```

- デフォルト効果: 「おすすめ」がデフォルトタブ

## S_CAFE_DETAIL（カフェ詳細）

### モバイル

```
+----------------------------------------+
| [<戻る]                          [⋯]  |
+----------------------------------------+
| [ヒーロー画像 or 写真グリッド]         |
+----------------------------------------+
| {カフェ名}   [✓公式] <- verified なら表示
| 投稿 128件 · 渋谷区 · 徒歩3分          |
+----------------------------------------+
| [行きたい] [お気に入り]  [地図で見る]  |
+----------------------------------------+
| 営業時間                                |
| 月火水木金 08:00 - 22:00               |
| 土日      09:00 - 21:00                |
| 定休日    なし                          |
+----------------------------------------+
| 混雑度                                  |
| ┌────────────────────────────────┐   |
| │ 【今の混雑度】                    │  | <- 直近30分以内のデータあり
| │ 空いてる  ●●●○○ 普通  ○○○○○ 混雑│  |
| │ 直近レポート: 25分前 (3件)       │  |
| └────────────────────────────────┘   |
| ─── または（直近データなし時）───      |
| ┌────────────────────────────────┐   |
| │ 【いつも今頃はこんな感じ】        │  | <- 過去4週間の同時間帯平均
| │ 空いてる  ●●○○○ 普通  ○○○○○ 混雑│  |
| │ 過去データ: 12件                  │  |
| └────────────────────────────────┘   |
| ─── または（データなし時）───          |
| ┌────────────────────────────────┐   |
| │ まだ混雑度情報がありません        │  |
| │ 最初の報告者になりませんか？      │  |
| └────────────────────────────────┘   |
| [今の混雑度を報告する]                  |
+----------------------------------------+
| 時間帯別の混雑傾向                      |
| ┌────────────────────────────────┐   |
| │  月 火 水 木 金 土 日            │  |
| │6 ░░░░░░░                         │  | <- 折れ線 or ヒートマップ
| │12 ▓▓▓▓░░░                        │  |
| │18 ▓▓▓▓▓▓▓                        │  |
| └────────────────────────────────┘   |
| ※ 過去4週間のユーザー投稿より         |
+----------------------------------------+
| 住所 / 電話 / Web                       |
+----------------------------------------+
| ┃オーナーから┃                          | <- ⭐️ 幹C: オーナー限定投稿セクション
| ┌────────────────────────────────┐   |
| │ [✓公式] 今日のおすすめ           │   |
| │ 本日の日替わりケーキは...        │   |
| │                      2h前 [❤] │   |
| └────────────────────────────────┘   |
| ┌────────────────────────────────┐   |
| │ [✓公式] 豆知識                  │   |
| │ 当店で使っている豆は...          │   |
| │                      1日前     │   |
| └────────────────────────────────┘   |
|                    [もっと見る ▶]      |
+----------------------------------------+
| ┃投稿┃ 基本情報                        | <- タブ
| ─────                                  |
+----------------------------------------+
| [投稿グリッド 2列]                     |
| ...                                    |
+----------------------------------------+
```

- 「行きたい」「お気に入り」は分けて配置（マイページで別リスト管理）
- **星レーティング・レビュー機能は MVP では持たない**（`cafes` に評価カラムも `reviews` テーブルもない）。信頼の手がかりは投稿件数・公式バッジ・混雑度で表現する
- 公式バッジは経営者認証済みのみ
- **オーナー限定投稿は「オーナーから」セクションに集約表示**（一般投稿と区別、幹C）
- オーナー投稿の `official_format` に応じてアイコンをつける（今日のおすすめ / 豆知識 / 臨時休業 / 新メニュー）

### PC

```
+----------------------------------------------------------------------------------+
| ヘッダー                                                                          |
+---------+------------------------------------------------------+-----------------+
| サイド  | [ヒーロー画像 パノラマ]                              | 地図            |
| ナビ    +------------------------------------------------------+ [埋め込み地図]  |
|         | {カフェ名} [✓公式] 投稿 128件                       |                 |
|         | [行きたい] [お気に入り]  [投稿する]                  | 営業時間        |
|         +------------------------------------------------------+ ...             |
|         | ┃投稿┃ 基本情報 混雑度                              |                 |
|         | ────────                                             | 電話・Web       |
|         | [投稿グリッド 3列]                                   |                 |
|         | ...                                                  |                 |
+---------+------------------------------------------------------+-----------------+
```

- 右カラムに地図・営業時間・連絡先を固定表示
- **実装ではモバイルの「[地図で見る]」を `/map` への遷移ではなく、その場で埋め込み地図を
  開閉するトグルにした**（2026-09-28）。PC と同じ地図コンポーネントを流用でき、`/map` 側に
  カフェ選択状態を受け渡す改修が不要なため。座標未収集のカフェ（バックフィル未実施分）では
  ボタンごと出さない（pending-items D30）

## S_USER_PROFILE_PUBLIC（他人のプロフィール）

### モバイル

```
+----------------------------------------+
| [<戻る]                          [⋯]  | <- ⋯: 通報 / ブロック
+----------------------------------------+
|         [アバター 大]                  |
|         {display_name}                 |
|         @{username}                    |
|         {bio}                          |
+----------------------------------------+
| 投稿 42 · フォロー 128 · フォロワー 89 |
+----------------------------------------+
| [フォロー]                             | <- 未ログイン時: [ログインしてフォロー]
+----------------------------------------+
| バッジ                                  |
| [街歩き入門][朝カフェマスター]...     |
+----------------------------------------+
| ┃投稿┃ 行きつけ                        | <- タブ
| ─────                                  |
+----------------------------------------+
| [投稿グリッド 3列]                     |
+----------------------------------------+
```

- 自分のプロフィール（`S_MYPAGE`）とは別画面。フォローボタン・通報等の対人要素を持つ
- バッジ表示はゲーミフィケーション + 社会的信頼形成
- **「お気に入り」「行きたい」「保存」は他人には出さない** — `user_cafe_lists` / `post_bookmarks` の RLS は SELECT も本人限定（[tables.md](../../architecture/data-model/tables.md#user_cafe_lists) 参照）。公開できるのはオーナーが認定した **行きつけ**（`regular_customers`、RLS 全公開）のみ

| ナビ    | @{username}   [フォロー]                            [⋯]                |
|         | {bio}                                                                   |
