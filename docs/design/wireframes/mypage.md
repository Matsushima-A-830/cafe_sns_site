# マイページ・通知・設定

ログインユーザーの自分向け画面群。共通コンポーネントは [README.md](./README.md) を参照。

## S_MYPAGE（マイページ）

自分のプロフィール + 各リストへの入り口。他人向け（`S_USER_PROFILE_PUBLIC`）とは編集ボタン等が異なる。

### モバイル

```
+----------------------------------------+
| [ロゴ]              [検索][通知][+]    |
+----------------------------------------+
|         [アバター 大]                  |
|         {display_name}                 |
|         @{username}                    |
|         {bio}                          |
|                                        |
|         [プロフィールを編集]           |
+----------------------------------------+
| 投稿 42 · フォロー 128 · フォロワー 89 |
+----------------------------------------+
| バッジ                                  |
| [街歩き入門] [朝カフェマスター]        |
| [制覇マップを見る ▶]                    |
+----------------------------------------+
| ⭐️ 私の行きつけ (3)             (幹C) |
| ┌──────┐ ┌──────┐ ┌──────┐            |
| │[写真]│ │[写真]│ │[写真]│            |
| │{店A}│ │{店B}│ │{店C}│            |
| │常連 │ │常連 │ │常連 │            |
| └──────┘ └──────┘ └──────┘            |
|                    [すべて見る ▶]      |
+----------------------------------------+
| リスト（ショートカット）                |
| ┌──────────────────┐┌─────────────┐  |
| │お気に入り     42 ▶│││行きたい 18 ▶│  |
| └──────────────────┘└─────────────┘  |
| ┌──────────────────┐┌─────────────┐  |
| │保存投稿       27 ▶│││下書き    3 ▶│  |
| └──────────────────┘└─────────────┘  |
+----------------------------------------+
| ┃お気に入り┃ 行きたい 保存 下書き       | <- タブで内容切替
| ─────                                  |
| プレビュー (最新5件)      [すべて見る▶]|
| ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐        |
| │サム│ │サム│ │サム│ │サム│ │サム│        |
| └───┘ └───┘ └───┘ └───┘ └───┘        |
+----------------------------------------+
| ┃投稿┃  自分の投稿                      |
| ─────                                  |
+----------------------------------------+
| [投稿グリッド 3列]                     |
+----------------------------------------+
| [ホーム][発見][+投稿][地図]┃マイ┃      |
+----------------------------------------+
```

**ハイブリッドUIの設計意図:**
- 上部の**4カード**は各リストへの明快なショートカット（件数バッジ付き）
- 中段の**タブ切替プレビュー**で、マイページを離れずに直近5件を確認できる
- 「すべて見る」でそれぞれの一覧画面 (`S_FAVORITES` / `S_WANT_TO_GO` / `S_BOOKMARKS` / `S_DRAFTS`) へ遷移
- 下段は「自分の投稿」タイムライン

**ピークエンド則:** バッジは獲得時のアニメーション（マイページ訪問時に軽く光る）

### モバイル

```
+----------------------------------------+
| [<戻る]  プロフィール編集   [保存]     |
+----------------------------------------+
| プロフィール画像                        |
|         [○ アバター ] [変更]           |
+----------------------------------------+
| ユーザーネーム                          |
| < @username >  (変更不可)              |
+----------------------------------------+
| 表示名                                  |
| < ______________________ >             |
+----------------------------------------+
| 自己紹介                                |
| < ______________________ >             |
| < ______________________ >             |
+----------------------------------------+
| ホームエリア                            |
| [渋谷 ▼]                                |
+----------------------------------------+
```

- 変更検知: 保存ボタンは変更があるまで disabled
- 離脱時: 変更があれば確認ダイアログ（損失回避）

## S_FAVORITES / S_WANT_TO_GO / S_BOOKMARKS

3つとも同じレイアウトパターン。データソースだけ違う。

### モバイル

```
+----------------------------------------+
| [<戻る]  お気に入りカフェ (42)         |
+----------------------------------------+
| [並び順: 追加日 ▼]  [表示: リスト ▼] |
+----------------------------------------+
| ┌────────────────────────────────┐   |
| │ [サムネ] {カフェ名}   投稿12    │   |
| │         渋谷区 · 徒歩3分         │   |
| │         追加: 2週間前            │   |
| │                          [⋯]    │   | <- ⋯: メモ編集 / リストから削除
| └────────────────────────────────┘   |
| ...                                    |
+----------------------------------------+
```

**タブ切替（同一画面で3リストを切り替える版も検討可）:**

```
+----------------------------------------+
| ┃お気に入り┃ 行きたい  保存投稿        |
| ─────                                  |
+----------------------------------------+
```

- 「行きたい」と「お気に入り」は意味が近いためタブ内切替で認知負荷を下げる案

### PC

- グリッド表示 4列
- 右カラムに地図（お気に入りカフェを一括表示 → **エリア偏り可視化はゲーミフィケーション要素**）

## S_DRAFTS（下書き一覧）

損失回避の一環として、明確な入り口を用意。

### モバイル

```
+----------------------------------------+
| [<戻る]  下書き (3)                    |
+----------------------------------------+
| ┌────────────────────────────────┐   |
| │ [サムネ] {カフェ名}              │   |
| │         "本文冒頭..."           │   |
| │         最終保存: 5分前          │   |
| │         [続きを書く]  [削除]     │   |
| └────────────────────────────────┘   |
| ┌────────────────────────────────┐   |
| │ ...                              │   |
| └────────────────────────────────┘   |
+----------------------------------------+
| 30日後に自動削除されます              | <- 注意書き（損失予告）
+----------------------------------------+
```

- 削除は確認ダイアログ必須
- 「続きを書く」で `S_POST_BLOG` or `S_POST_SHORT` に復元

## S_NOTIFICATIONS（通知）

### モバイル

```
+----------------------------------------+
| [<戻る]  通知             [すべて既読] |
+----------------------------------------+
| ┃すべて┃ フォロー コメント いいね      | <- フィルタタブ
| ─────                                  |
+----------------------------------------+
| ● {ユーザー} があなたの投稿にいいね     |
|   [サムネ]                    2分前    |
|                                        |
| ● {ユーザー} があなたをフォロー         |
|   [アバター]  [フォローバック]  1h    |
|                                        |
| ○ {ユーザー} がコメントしました         |
|   「素敵ですね！」            3h      |
|                                        |
| ● バッジ「街歩き入門」を獲得！         |
|   [見る]                      1日前   |
+----------------------------------------+
```

- 未読は左端に丸マーク
- **返報性:** フォロワー通知には「フォローバック」を1タップで実行可能に
- バッジ名は [seed/badges-initial-set.md](../../seed/badges-initial-set.md) の20個から取る（画面例も実在するコードに揃える）

### PC

- サイドナビ内「通知」項目、または `/notifications` ページ
- タブ切替 + 無限スクロール

## S_SETTINGS（設定）

### モバイル

```
+----------------------------------------+
| [<戻る]  設定                          |
+----------------------------------------+
| アカウント                              |
| ● メールアドレス変更                ▶  |
| ● 電話番号変更                       ▶  |
| ● パスワード変更                     ▶  |
| ● アカウントを削除                   ▶  |
+----------------------------------------+
| プライバシー                            |
| ● 位置情報の使用            [ON/OFF]   |
| ● おすすめ表示に活用        [ON/OFF]   |
| ● ブロック中のユーザー               ▶  |
+----------------------------------------+
| 通知                                    |
| ● プッシュ通知               [ON/OFF]  |
| ● メール通知                 [ON/OFF]  |
| ● いいね                     [ON/OFF]  |
| ● コメント                   [ON/OFF]  |
| ● フォロー                   [ON/OFF]  |
+----------------------------------------+
| 表示                                    |
| ● 文字サイズ                 [標準 ▼] |
+----------------------------------------+
| その他                                  |
| ● 利用規約                          ▶  |
| ● プライバシーポリシー              ▶  |
| ● 特定商取引法に基づく表記          ▶  |
| ● お問い合わせ                      ▶  |
| ● ライセンス情報                    ▶  |
|                                        |
| [ログアウト]                            |
+----------------------------------------+
| バージョン 1.0.0                        |
+----------------------------------------+
```

- アカウント削除は最下部の危険操作扱い、二段階確認 + パスワード再入力
- 通知トグルは初期値: 全てON（デフォルト効果）※CTAで後から絞りやすい
- **テーマ（ダークモード）切替は MVP では出さない** — [design-system.md §6](../design-system.md#6-ダークモード) で未対応と決めているため。対応時に `/settings/display` へ追加する
- 言語切替も同様に MVP では出さない（日本語のみ。i18n の導入判断は [routing.md 未確定事項](../../architecture/routing.md#未確定事項実装時に判断)）

## S_BLOCKED_USERS（ブロック管理）

### モバイル

```
+----------------------------------------+
| [<戻る]  ブロック中のユーザー (3)      |
+----------------------------------------+
| [アバター] {ユーザー名}   [解除]       |
| [アバター] {ユーザー名}   [解除]       |
| [アバター] {ユーザー名}   [解除]       |
+----------------------------------------+
| ブロックすると、相手はあなたの投稿・   |
| プロフィールを見られなくなります。      |
+----------------------------------------+
```

- 解除は確認ダイアログ経由（誤操作防止）
